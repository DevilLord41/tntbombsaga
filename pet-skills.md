# Pet skills

## How skill upgrades work

- Pet skills go up to **level 5**.
- Upgrading a skill one level costs **1 Skill Book** of the next level: level 1→2 takes a Skill Book II, 2→3 a Skill Book III, and so on up to V.
- Replacing a skill (re-rolling it into another skill) costs **1 Skill Book** of the skill's current level.
- Only the pet's 3rd skill slot and above can be upgraded or replaced; the first two slots cannot be changed.
