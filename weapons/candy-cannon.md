## Ultimate: Sugar Bomb

Fires 5 consecutive shells. If they hit allies, each shell restores HP. If they hit enemies, each shell deals base damage. (The shells do not create craters.)

| Levels | Base DMG | Additional |
|---|---|---|
| S0 - S3 | 80% | Restores 3% HP when hitting an ally. |
| S4 - S7 | 85% | Restores 3.2% HP when hitting an ally. |
| S8 - S11 | 90% | Restores 3.4% HP when hitting an ally. |
| S12 - S13 | 100% | Restores 3.5% HP when hitting an ally. |
